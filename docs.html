Docs & Setup

The single source of truth for training material and developer docs: setup guides, starter repo links, sandbox access, MCP documentation, and connector documentation. Masterclass owners publish supporting material here before each session; questions raised in sessions become FAQ entries.

Sandbox-only policy: all agent builds use Pine Labs sandbox rails and test merchant configurations. Never use production credentials or live merchant data. See Security and governance below.

What you'll find below — four kinds of docs

Setup guide

Step-by-step instructions you follow in order to get something working.

Reference

Lookup material — what exists, what it does, and its parameters.

Template

A starter file or repo you copy and adapt, not just read.

Policy

Rules you must follow — not optional, not a how-to.

Every item below is tagged with its type, so you know whether you're about to read a policy, follow a setup guide, look something up, or copy a template — before you click.

Every setup guide follows the same shape

  1. 1. Objective — what you'll have working by the end.
  2. 2. Prerequisites — access, tools, or accounts you need first.
  3. 3. Steps — numbered, copy-pasteable, one action per step.
  4. 4. Verify — how to confirm it actually worked.
  5. 5. Troubleshooting — the errors people hit, and the fix.

Every reference doc follows the same shape

  1. 1. What it is — one paragraph, plain language.
  2. 2. Where it fits — how it connects to the rest of the stack.
  3. 3. Fields / parameters — the details you'll actually look up.
  4. 4. Example — a real request/response or config snippet.
  5. 5. Related links — the guides that use this reference.
