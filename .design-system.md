# Design System

Category: SaaS / B2B internal enablement portal (with community/edtech participation flows layered on top).

Palette:
- Navy `#13304a` (primary, header/hero/footer)
- Navy deep `#0e2437` (footer, dark accents)
- Teal `#0f9691` / teal dark `#0b706c` (CTAs, active states)
- Amber `#f2a71b` (brand accent, top strip, highlight text)
- Paper `#f6f8fa` (page background), Ink `#1c2b36` (body text)

Fonts:
- Headline: Syne (700/800) — geometric, confident, not a generic default
- Body: Plus Jakarta Sans — highly legible, professional

Key decisions:
- Replaced default Geist fonts (read as an unstyled starter template) with Syne + Plus Jakarta Sans.
- Mobile nav uses a real hamburger/drawer component (`components/NavBar.tsx`) instead of horizontal scroll — the original nav overflowed and cut off links on narrow viewports.
- Broke up repeated identical card grids: home page's 7-step process is now a connected vertical timeline, not another card grid; Docs page groups 11 sections into 3 labeled, color-coded rows instead of one uniform 11-card grid.
- No fabricated data anywhere: submission form/gallery are honestly labeled as non-functional on this static (GitHub Pages) deployment rather than faking a working backend.

Social assets:
- `public/og-image.png` (1200×630), `public/icon.png` + `favicon-16.png` + `apple-icon.png` generated to match the navy/teal/amber identity — wired via `app/layout.tsx` metadata (icons, openGraph, twitter).

Taste record: no design-shotgun run — an existing, working navy/teal/amber identity was already in place and validated by the operator; this pass was an audit/refinement (typography, mobile nav, layout monotony, social previews), not a re-concept.
